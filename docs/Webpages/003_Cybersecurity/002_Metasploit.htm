The following is a cheatsheet using my understanding of the tools that have come across while studying and experimenting with pentesting on HackTheBox and TryHackMe.

Metasploit Usage

Running MSF

Start MSF by running the following commands in the terminal.

msfconsole

Checking for existing exploits

You can use the following commands to check if there are any existing exploits depending in the information that you have.

#search cve:2009 type:exploit
#search cve:2009 type:exploit platform:-linux
#search cve:2009 -s name
#search type:exploit -s type -r
  • cve:[CVE number] -- search by Common Vulnerabilities and Exposures(CVE) number
  • platform:[OS name] -- search by OS name
  • type:[Module type] -- Searches the Module type according to the following types
    • Auxiliary
      • Administration - Modify, operate, or manipulate something on target machine
      • Analyzing - Tools that perform analysis, mostly password cracking
      • Gathering - Gather, collect, or enumerate data from a single target
      • Denial of Service - Crash or slow a target machine or service
      • Scanning - Scan targets for known vulnerabilities
      • Server Support - Run Servers for common protocols such as SMB, FTP, etc
    • Encoder
      • Encoders take the raw bytes of a payload and run some sort of encoding algorithm
    • Evasion
      • Allows users to generate payload that can evade Antiviruses
    • Exploit
      • Uses known vulnerabilities to execute arbitary code
    • Nop
      • Generate "No Operation" instructions that are of then used in conjuncture with stack buffer overflows
    • Payloads
      • Usually used with exploit module, this module changes the payload sent by the exploit module
  • -h --Help banner
  • -I --Ignore the command if the only match has the same name as the search
  • -o [filename] --Send output to a file in csv format
  • -r [column] --Reverse the order of search results to descending order
  • -S [filter] --Regex pattern used to filter search results
  • -s [column] --Sort search results by the specified column in ascending order
  • -u --Use module if there is one result

Running exploit

After finding the right module to run, you can use the following command to run the exploit

msfconsole
