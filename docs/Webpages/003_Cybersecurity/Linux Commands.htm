The following is a cheatsheet for well known linux commands.

Linux Command List

OS commands
Command Usage Further Information/Documentation(if any)
Apt

Package manager for linux distros

  • apt install [package name] -y -- Installs package
  • apt list --installed -- list installed packages
  • sudo apt update -y && sudo apt full-upgrade -y && sudo apt autoremove -y && sudo apt clean -y && sudo apt autoclean -y -- One line package updates
man [command]

Displays information on other commands and how they work
apropos [string]

Searches the man page descriptions for a specified string
whatis [command]

Displays a description of a command on a single line

User permissions commands
whoami Check who the current user is
useradd

Add a user to the system

  • -g [group name] -- specify main group, GROUP MUST EXIST BEFOREHAND
  • -G [group1,group2,group3,...] -- Specifies which EXISTING group to add the new user to
usermod

Modifies an existing user

  • -g [group name] -- Changes the user's main group, GROUP MUST EXIST BEFOREHAND
  • -a -G [group1,group2,group3,...] -- Specifies which EXISTING group to add the new user to
  • -d [new directory] -- changes the user's home directory
  • -l [new username] -- Changes the user's login name
  • -L -- Locks the account so the user can't log in
  • -r -- delete all files in the user's home directory
